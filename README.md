## How to Run
1. Make sure Python is installed on your computer.
2. Open the terminal or command prompt.
3. Navigate to the folder containing the Python file.
4. Run the script using:

```bash
python filename.py
```

Example:

```bash
python exercise1.py
```

If you use Python 3, you can also run:

```bash
python3 filename.py
```
